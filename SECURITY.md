# Security policy

## Reporting a vulnerability

Please open a GitHub security advisory rather than a public issue when a report
could expose private agent data or provide a practical path-bypass exploit.

## Supported versions

Only the latest tagged release receives security fixes during the alpha period.

## Security posture

This tool is a local change-control reference implementation, not an encrypted
secret store or compliance product. Review the privacy and threat model before
using it with sensitive data.
